# Media-Forge
MediaForge is a lightweight, drag-and-drop media management tool designed to clean up and standardize movie and TV show libraries. Built with Python and CustomTkinter, it parses release group naming conventions, renames files into clean formats, and integrates with the TMDB API and yt-dlp to automatically fetch official posters, episode metadata, and trailers.

    Drag-and-Drop GUI: Clean, dark-mode interface built with CustomTkinter.

    Smart Parsing: Automatically extracts titles, years, seasons, and episodes from messy release names.

    Metadata Integration: Fetches official movie/series/season posters and episode names via the TMDB API.

    Automated Trailers: Uses yt-dlp to download official YouTube trailers alongside your media.

    Library Cleanup: Strips out junk files (.url, Thumbs.db) and prunes empty directories.
